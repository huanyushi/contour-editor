# Complex Contour Editor

复平面围道编辑器，用于绘制由线段和圆弧组成的积分路径，添加奇点标记与 LaTeX 标签，并导出适合笔记、讲义和文章使用的矢量或位图插图。

**[在线绘制围道 → https://huanyushi.github.io/contour-editor/](https://huanyushi.github.io/contour-editor/)**

打开网页即可使用，无需安装 Node.js 或 MathJax。数学排版代码和所需的 TeX 字形已随网站打包，可在其他电脑的浏览器中直接加载。

项目基于 React、TypeScript 和 Vite，使用原生 SVG 绘图、本地 MathJax 排版和 Lucide 界面图标。编辑、项目保存和图片生成均在浏览器中完成。

## 功能概览

围道由共享端点连接，拖动端点时，相邻路径段和填充会同步更新。数学坐标、对象样式和画布视图分别管理，便于在调整图形的同时保持坐标与比例准确。

| 功能     | 支持内容                                           |
| -------- | -------------------------------------------------- |
| 围道编辑 | 线段、三点圆弧、开放／闭合路径、增删端点和反转方向 |
| 多选操作 | 框选、Ctrl／⌘ 点选、键盘删除和批量修改外观         |
| 示例模板 | 9 种常见围道，一键生成可编辑的端点、圆弧和标签     |
| 独立对象 | 标记点、公式及连接已有点的独立线段／圆弧           |
| 数学标签 | TeX base／AMS 命令，可调整字号、颜色和位置         |
| 图形样式 | 线宽、线型、方向箭头、点样式、纯色及斜线填充       |
| 视图控制 | 缩放、平移、适应图形、网格与坐标轴设置             |
| 编辑历史 | 撤销／重做，最多保留 100 步，一次拖动计为一步      |

## 本地运行

需要 Node.js **22.12 或更高版本**。在项目目录执行：

```bash
npm ci
npm run dev
```

开发服务器地址通常为 <http://localhost:5173/contour-editor/>，以终端输出为准。生产构建使用 `npm run build`，生成的静态文件位于 `dist/`；可通过 `npm run preview` 本地预览，同样访问 `/contour-editor/` 路径。

## 工作区与交互

界面采用全屏画布、左侧绘图工具和右侧对象属性面板。侧栏可折叠并独立滚动，窄屏时以覆盖面板呈现。工具名称与提示通过悬停显示，对象列表提供另一种选择对象的方式。

导出和应用设置弹窗会在点击外部时自动收起；也可再次点击入口或按 `Esc` 关闭。

选择工具下，点击端点、路径、标签或实际填充区域会展开对应属性；点击空白、孔洞或未填充的内部不会展开属性，也不会切换当前选择。

选择、平移下方的“框选”工具可拖出矩形，选中完整位于框内的对象；圆弧按完整曲线范围判断，公式和标签按实际文字范围判断。拖动选中的矩形区域可整体平移，按住 `Ctrl／⌘` 拖动可追加框选。`Ctrl／⌘＋单击` 可增减选中项，对象列表也支持此操作；点选多选仅高亮对象，不显示选择框。切换左侧工具会取消当前选择。框选操作框提供删除与取消按钮，右侧“多选属性”可批量修改颜色、线宽、点半径及适用文字的字号；外观不一致时会显示“多种”或“颜色不一”。`Esc` 可取消正在进行的框选、对象拖动或平移；未拖动时可清除多选。

单选或多选后，按 `Backspace`／`Delete` 删除当前选择，一次批量删除或外观修改只计一步撤销。删除路径段保留端点，删除端点同时移除相连路径段，断开的路径不自动重连或填充；可以删除到空画布并继续绘制。单独删除附属标签仅隐藏文字。编辑文字、数值或颜色输入框时，删除键保留输入框原本的行为。

颜色控件统一提供 8 个常用色，点击“更多…”后才展开自定义 RGB 颜色选择器。

“线段”工具依次选择两个已有点来建立连接。独立线段可转换为圆弧，并保留原围道的填充。重复点击已有点、线段或公式会选中原对象；独立点和公式工具下也可直接拖动已有对象。

画布内滚轮以鼠标位置为中心缩放；平移支持手掌工具、中键拖动，以及画布聚焦后的空格＋拖动。右下角定位图标“回到原点”只重置视图中心，保留缩放与两轴比例。网格、坐标轴、吸附和倍率集中在“视图设置”中。实轴和虚轴标签默认为 `\mathrm{Re}`、`\mathrm{Im}`，可在其中修改 LaTeX 并点击“应用轴标签”，留空可隐藏标签。视图设置的“在原点追加顶点”支持精确添加端点。默认锁定两轴单位比例为 1:1，窗口尺寸和侧栏开合只改变可见范围，保持图形的数学坐标与单位长度。

整数吸附阈值为 8 个屏幕像素，`Alt` 可临时绕过吸附，属性面板中的数值输入始终保持精确值。标签外观即时生效，LaTeX 文字在点击“应用”后更新。撤销快捷键为 `Ctrl／⌘＋Z`，重做为 `Ctrl／⌘＋Shift＋Z` 或 `Ctrl＋Y`；选择和视图调整不进入编辑历史。

标签水平／垂直偏移滑条的常规范围为 **−100～100px**，表示屏幕像素，与数学缩放无关。悬停滑条时，滚轮每次微调 1px，不滚动面板；其他滑条仍用于普通面板滚动。旧项目中超出常规范围的偏移会原样显示，可逐步调回，不会被静默截断。

### 示例模板（Contour Templates）

点击左侧工具栏底部、对象列表上方的“示例模板”图标，在双列卡片中选择围道。模板面板与对象列表互相切换，可通过收起按钮或 `Escape` 关闭。宽屏时面板与画布并排，关闭后画布恢复可用宽度；窄屏时以覆盖面板呈现，载入模板后自动关闭。

模板选自[围道示例 PDF](https://github.com/huanyushi/pdf-study-notes/blob/main/latex/tikz-example-contour-integration.pdf)，共 9 种：

- 圆形围道、上半圆围道、半圆凹口围道
- 扇形围道、矩形围道
- 钥匙孔围道、钥匙孔避让奇点
- Bromwich 围道、Bromwich 割线围道

未恢复本地草稿时，默认显示矩形模板。单击卡片直接切换围道，支持撤销。网格、轴标签及外观、吸附、编辑手柄及横纵轴比例锁定等视图设置在模板间共用；载入时自动调整视图中心与缩放，在边缘为轴标签和箭头留白，并保留未锁定时的两轴比例。模板标签中的常数 e 和虚数单位 i 使用正体。生成的端点、圆弧、标签和填充均可继续编辑，支持 JSON 保存和 SVG／PNG 导出。

半圆凹口的外弧为逆时针，小半圆为顺时针。钥匙孔采用与 TikZ 原稿一致的有限宽度割线，内圆、割线及避让奇点的区域保持留空。模型支持断开的开放路径，填充仅在完整闭合围道中显示；Bromwich 模板省略辅助半径线及虚线延长线。

## 项目文件与图片导出

项目以 **JSON** 保存，包含已应用的几何、标签、公式、样式和视图设置，可重新打开继续编辑。浏览器会自动保存本地草稿并在刷新后恢复；跨设备或长期保存应使用项目文件。窄屏会隐藏顶部保存状态，自动保存仍然生效。

旧的版本 1 项目仍可读取；包含独立线段／圆弧连接的项目使用版本 2，以保留已有点之间的引用关系。

图片支持 **SVG** 和 **PNG**，可选择白色／透明背景，以及是否包含坐标轴、网格和端点标记。SVG 保留矢量路径和数学字形；PNG 提供 **1×、2×、3×** 分辨率倍率，默认使用 2×，菜单会显示对应的实际尺寸。

默认使用“适应图形（完整导出）”：按完整图形、标签及留白自动确定长宽，宽图会导出为宽图；过大的图形会在导出副本中等比适配。也可选择“当前视图（800×600）”，按当前中心和缩放导出固定区域。SVG 和 PNG 使用同一导出范围，导出不会改变编辑画布或历史。

## GitHub Pages 发布

在线站点由本仓库独立发布到 <https://huanyushi.github.io/contour-editor/>。Vite 的 `base` 配置为 `/contour-editor/`，确保脚本和样式使用正确的项目路径。

向 `main` 分支推送后，[部署工作流](.github/workflows/deploy-pages.yml)会自动安装依赖、运行单元和组件测试、构建网站，并将 `dist/` 作为 Pages 产物部署。也可以在仓库的 Actions 页面手动运行“Deploy to GitHub Pages”。构建产物通过工作流上传，无需提交 `dist/`，也无需同步博客仓库。

首次启用时，仓库的 **Settings → Pages → Build and deployment → Source** 应选择 **GitHub Actions**。部署结果可在 Actions 中查看：`build` 和 `deploy` 均成功后，通过部署记录中的站点链接访问并刷新确认。

## 开发与验证

界面布局位于 `src/app/`，围道模型和交互位于 `src/features/contour/`，持久化及导出位于 `src/features/project/`。几何、视图投影和数学排版等基础代码放在 `src/lib/`。实现约定见 [AGENTS.md](AGENTS.md)。

| 命令                                      | 用途                |
| ----------------------------------------- | ------------------- |
| `npm run lint`                            | 代码规范检查        |
| `npm run format` / `npm run format:check` | 格式化／格式检查    |
| `npm run typecheck`                       | TypeScript 类型检查 |
| `npm test` / `npm run test:watch`         | 单元和组件测试      |
| `npm run test:e2e`                        | 浏览器测试          |
| `npm run build`                           | 生产构建            |

浏览器测试使用 Playwright，首次运行前需要安装 Chromium：

```bash
npx playwright install chromium
```

Linux 系统依赖可通过 `npx playwright install-deps chromium` 安装；中文截图需要中文字库，例如 `fonts-noto-cjk`。测试会自动启动开发服务器，以桌面覆盖完整流程，并在窄屏下验证与尺寸有关的交互。
