# Complex Contour Editor

复平面围道编辑器，用于绘制由线段和圆弧组成的积分路径，添加奇点标记与 LaTeX 标签，并导出适合笔记、讲义和文章使用的矢量或位图插图。

**[在线绘制围道 → https://huanyushi.github.io/contour-editor/](https://huanyushi.github.io/contour-editor/)**

打开网页即可使用，无需安装 Node.js 或 MathJax。数学排版代码和所需的 TeX 字形已随网站打包，可在其他电脑的浏览器中直接加载。

浏览器标签页使用与 [Huanyu Shi 个人主页](https://huanyushi.github.io/) 相同的站点图标，图标文件随本项目部署，无需从个人主页加载。

左上角的应用标志采用有向闭合围道与编辑点，箭头位于右下弧段并沿切线指向，使用静态 SVG 绘制，不依赖系统字体。

项目基于 React、TypeScript 和 Vite，使用原生 SVG 绘图、本地 MathJax 排版和 Lucide 界面图标。编辑、项目保存和图片生成均在浏览器中完成。

## 功能概览

围道由共享端点连接，拖动端点时，相邻路径段和填充会同步更新。数学坐标、对象样式和画布视图分别管理，便于在调整图形的同时保持坐标与比例准确。

| 功能     | 支持内容                                           |
| -------- | -------------------------------------------------- |
| 围道编辑 | 线段、三点圆弧、开放／闭合路径、增删端点和反转方向 |
| 多选操作 | 框选、Ctrl／⌘ 点选、键盘删除和批量修改外观         |
| 多画布   | 最多 10 张独立画布，自动保存、复制、重命名与切换   |
| 示例模板 | 9 种常见围道，先预览，再新建独立画布               |
| 独立对象 | 标记点、公式及连接已有点的独立线段／圆弧           |
| 奇点绕行 | 局部绕行、一般路径平行接入、两岸奇点联动避让       |
| 数学标签 | TeX base／AMS 命令，可调整字号、颜色和位置         |
| 图形样式 | 线宽、线型、方向箭头、点样式、纯色及斜线填充       |
| 视图控制 | 缩放、平移、适应图形、网格与坐标轴设置             |
| 编辑历史 | 撤销／重做，最多保留 100 步，一次拖动计为一步      |

## 本地运行

需要 Node.js **22.12 或更高版本**。在项目目录执行：

```bash
npm ci
npm run dev
```

开发服务器地址通常为 <http://localhost:5173/contour-editor/>，以终端输出为准。生产构建使用 `npm run build`，生成的静态文件位于 `dist/`；可通过 `npm run preview` 本地预览，同样访问 `/contour-editor/` 路径。

## 工作区与交互

界面采用全屏画布、左侧绘图工具和右侧对象属性面板。侧栏可折叠并独立滚动，窄屏时以覆盖面板呈现。工具名称与提示通过悬停显示，对象列表提供另一种选择对象的方式，并以统一的线性图标区分整体围道、直线和圆弧。

对象属性面板预留滚动条空间，展开或收起内容时不会因滚动条出现而改变表单宽度。“几何”“外观”“标签”等分组标题与展开后的子标题、表单统一左对齐，嵌套的圆弧参数也沿用相同边距。

顶栏为保存状态预留固定空间，状态变化不会挤动历史、保存和导出按钮。较长的恢复提示显示省略号，悬停可查看完整内容；窄屏仍隐藏常规保存状态。

左上角 logo 与应用标题是两个独立的页面刷新入口，不影响项目名称的重命名；两者均不显示悬停提示，标题悬停时仅轻微变色，不显示下划线。刷新恢复已保存内容，仍有未保存修改时浏览器会提示确认离开。

操作按钮的工具提示采用统一样式，鼠标悬停稍作停留后显示，键盘聚焦立即显示，按 `Esc` 或开始操作时收起。被省略的项目名称和保存状态仍可悬停查看完整文字。辅助文字增强对比度，主提交、普通操作和删除分别以实心强调、中性描边和红色描边区分；没有绕行绑定时不显示空标题，折叠属性组的内部表单不再重复绘制分隔线。

左侧工具按选择与导航、几何绘制、标注与样式分组，底部保留“画布与模板”、对象列表和折叠入口。顶栏右侧的 GitHub 图标可在新标签页查看项目源代码。

导出和应用设置弹窗会在点击外部时自动收起；也可再次点击入口或按 `Esc` 关闭。

选择工具下，点击端点、路径、标签或实际填充区域会展开对应属性；点击空白、孔洞或未填充的内部不会展开属性，也不会切换当前选择。

选择、平移下方的“框选”工具可拖出矩形，选中完整位于框内的对象；圆弧按完整曲线范围判断，公式和标签按实际文字范围判断。拖动选中的矩形区域可整体平移，按住 `Ctrl／⌘` 拖动可追加框选。`Ctrl／⌘＋单击` 可增减选中项，对象列表也支持此操作；点选多选仅高亮对象，不显示选择框。切换左侧工具会取消当前选择。框选操作框提供删除与取消按钮，右侧“多选属性”可批量修改颜色、线宽、点半径及适用文字的字号；外观不一致时会显示“多种”或“颜色不一”。`Esc` 可取消正在进行的框选、对象拖动或平移；未拖动时可清除多选。

单选或多选后，按 `Backspace`／`Delete` 删除当前选择，一次批量删除或外观修改只计一步撤销。删除路径段保留端点，删除端点同时移除相连路径段，断开的路径不自动重连或填充；可以删除到空画布并继续绘制。单独删除附属标签仅隐藏文字。编辑文字、数值或颜色输入框时，删除键保留输入框原本的行为。

颜色控件第一排提供 8 个常用色，第二排最多保存 8 个自定义色，所有颜色控件共享并在刷新后保留。点击下一空格的“＋”展开自定义颜色选择器；满 8 格后隐藏“＋”。单击已保存色块会应用该颜色并打开编辑区，可替换颜色或点击“删除”。删除只清理色板记忆，不改变作品已应用的颜色，空出的格子可重新添加。

“围道端点”工具在空白处点击可连续追加端点。开放路径中，点击起点会接回起点并闭合；点击中间端点会只闭合从该点到末端的一段。例如 `1→2→3→4` 后点击 2，将得到 `2→3→4→2` 的闭环，同时保留 `1→2` 的连线。闭环按当前填充设置显示阴影，前面的连线不参与填充，并在对象列表中归为独立连接及独立点；原有方向、样式和标签保留，共享端点仍一起联动。一次闭合只计一步撤销。拖动已有端点仍只移动位置，不闭合；点击当前末点、直线原路折返或已闭合围道的端点不会重复闭合。断开的围道须先整理为一条连续路径；如已有绕行依赖使闭合无法安全完成，会保留原图并说明原因。

“线段”工具依次选择两个已有点来建立连接。独立线段可转换为圆弧，并保留原围道的填充。重复创建已有点、线段或公式会复用原对象；独立点和公式工具下也可直接拖动已有对象。

画布内滚轮以鼠标位置为中心缩放；平移支持手掌工具、中键拖动，以及画布聚焦后的空格＋拖动。右下角定位图标“回到原点”只重置视图中心，保留缩放与两轴比例。网格、坐标轴、吸附和倍率集中在“视图设置”中。实轴和虚轴标签默认为 `\mathrm{Re}`、`\mathrm{Im}`，可在其中修改 LaTeX 并点击“应用轴标签”，留空可隐藏标签。视图设置的“在原点追加顶点”支持精确添加端点。默认锁定两轴单位比例为 1:1，窗口尺寸和侧栏开合只改变可见范围，保持图形的数学坐标与单位长度。

网格吸附使用当前画布的自适应网格间距，阈值为 8 个 CSS 屏幕像素，超出时保持自由绘制。放大时可吸附小数网格交点，缩小时吸附较大间距的网格交点；两轴比例不同时分别使用各自间距。缩放、平移只更新后续操作的吸附目标，不改变已有点坐标；隐藏网格不关闭吸附。

独立点创建时，距离源直线或真实圆弧不超过 **8 CSS 像素**会优先投影到最近的源路径，再考虑网格吸附；围道和独立连接均可作为源，暂时隐藏的闭合边及自动生成的绕行部件不作为吸附目标。已在源路径上或其 8px 内的标记点，拖动开始时会捕获源几何，本次手势沿该路径移动；围道可沿相连路径跨过角点，独立连接只约束到所捕获的一段。创建或沿路径拖动时，若 8px 内有真正位于该有限路径上的网格交点，会精确吸附到该交点；附近的离路径网格交点不会把点拉离直线或圆弧。开始时远离路径的标记点保持自由拖动，与自身相连的独立连接不作为约束源。路径约束不受“网格吸附”开关影响。

按住 `Alt` 可临时绕过路径约束与网格吸附，自由创建或拖动；同一次拖动中松开 `Alt` 后，下次移动恢复开始时捕获的约束。属性面板中的数值输入始终保持精确值，不投影到路径。路径吸附只影响当前鼠标操作，不保存新的附着关系。标签外观即时生效，LaTeX 文字在点击“应用”后更新。撤销快捷键为 `Ctrl／⌘＋Z`，重做为 `Ctrl／⌘＋Shift＋Z` 或 `Ctrl＋Y`；选择和视图调整不进入编辑历史。

标签水平／垂直偏移滑条的常规范围为 **−100～100px**，表示屏幕像素，与数学缩放无关。悬停滑条时，滚轮每次微调 1px，不滚动面板；其他滑条仍用于普通面板滚动。旧项目中超出常规范围的偏移会原样显示，可逐步调回，不会被静默截断。

### 画布与模板

点击左侧工具栏底部、对象列表上方的“画布与模板”图标，在同一面板内切换“我的画布”和“示例模板”。该面板与对象列表共用位置和宽度；可通过收起按钮或 `Esc` 关闭，标签支持左右方向键切换。宽屏时面板与画布并排，窄屏时以覆盖面板呈现；只有实际切换或新建画布成功后才自动收起窄屏面板。

**我的画布**采用双列卡片，展示实际作品缩略图和名称，“当前”标记表示正在编辑的作品。点击其他卡片恢复其内容、名称及视图。最后一张“＋”卡片新建**完全空白**的画布并切换过去；第一次访问且没有旧草稿时，第一张仍使用原有矩形围道。

卡片下方可重命名、复制或删除。复制生成独立副本并自动选中，不共享后续修改；删除必须确认，删除最后一张时会明确提示将其重置为空白画布。最多保留 **10 张**，达到上限后不能继续通过加号、复制、模板或 JSON 导入新建，但仍可查看模板、编辑、保存及导出已有作品。

不同画布的撤销／重做互相隔离，切换回来可继续使用本次浏览器会话的历史；刷新后不恢复历史。切换清除选区、未提交的表单文字和未应用的绕行预览，不将它们保存到另一张作品。缩略图复用实际场景绘制，包括公式、独立连接及已应用绕行，不包含编辑手柄；鼠标移动、选择和平移不会重新生成缩略图。

**示例模板**中点击卡片，中间画布直接展示对应围道；侧栏只保留模板卡片，不再重复展示大预览和说明。浏览时可以拖动平移、滚轮缩放，不修改原作品、名称、历史或已保存视图；切回“我的画布”恢复原作品。收起侧栏仍可查看中央模板，窄屏也可先手动收起侧栏查看大图，再展开创建。

面板底部固定“＋ 新建画布”按钮，模板列表滚动时仍可操作。选好模板后点击按钮才创建独立作品，并以模板名称命名；编辑、项目保存和图片导出需先新建画布。达到 10 张上限后仍可浏览模板，只禁用新建。模板不替换已有作品，各张画布的视图设置相互独立。

模板选自[围道示例 PDF](https://github.com/huanyushi/pdf-study-notes/blob/main/latex/tikz-example-contour-integration.pdf)，共 9 种：

- 圆形围道、上半圆围道、半圆凹口围道
- 扇形围道、矩形围道
- 钥匙孔围道、钥匙孔避让奇点
- Bromwich 围道、Bromwich 割线围道

模板标签中的常数 e 和虚数单位 i 使用正体。生成的端点、圆弧、标签和填充均可继续编辑，支持 JSON 保存和 SVG／PNG 导出；创建新画布本身不作为另一张作品的撤销步骤。

半圆凹口的外弧为逆时针，小半圆为顺时针。钥匙孔采用与 TikZ 原稿一致的有限宽度割线，内圆、割线及避让奇点的区域保持留空。模型支持断开的开放路径，填充仅在完整闭合围道中显示；Bromwich 模板省略辅助半径线及虚线延长线。

半圆凹口模板在原点设置孤立奇点；钥匙孔和 Bromwich 割线模板在原点设置支点，通过真实绕行绑定生成凹口、内圆弧及割线两岸。钥匙孔避让奇点模板还包含实轴孤立奇点的两岸联动避让。半径、间距和外观采用当前绘图默认参数，可在绕行属性中继续调整；生成的端点用于联动调节，不是自由端点。其余五种基础模板不额外添加奇点。已保存的旧模板项目仍按原几何读取，不自动迁移。

## 项目文件与本地自动保存

项目以 **JSON** 保存，包含已应用的几何、标签、公式、样式和视图设置，可重新打开继续编辑。打开 JSON 默认导入为一张新画布，不覆盖已有作品；文件名称用作新画布名称。顶部“保存项目”和 SVG／PNG 导出始终只针对当前画布，单项目 JSON 格式不因多画布而改变。

每张画布通过浏览器的 **IndexedDB** 数据库独立自动保存，包括名称、已应用作品和视图；刷新或重新打开同一网站会恢复全部画布和上次选中的画布。只在事务写入完成后显示“已保存”；切换前等待保存，保存失败时留在当前作品，不悄悄切换。临时拖动中间位置、未应用的绕行预览及未提交文字不写入数据库。窄屏会隐藏常规顶部保存状态，但错误提示仍显示。

若浏览器禁止存储、空间不足或写入失败，会明确提示；可以“重试保存”，也可随时用“保存项目”手动下载当前作品。不能保存时，新建、复制、导入和切换会停止，当前作品仍可编辑和下载。检测到其他标签页已修改同一数据库时，停止旧页面的覆盖写入；请先下载本页作品备份，再刷新读取新数据，不支持跨标签页自动合并。

升级首次打开时，会尝试把旧 localStorage 草稿及名称迁移为第一张画布，确认新数据保存成功后才清理旧草稿。损坏的旧草稿或数据库不会静默删除或用默认内容覆盖；错误提示中的“下载本地数据备份”可下载原始记录，供人工恢复使用（该备份不是普通项目文件，不能直接用“打开项目”导入）。

旧草稿兼容代码只负责读取和迁移，不再继续向 localStorage 写入或维护另一套单画布自动保存；当前作品统一通过 IndexedDB 保存。

**本地保存不等于永久备份**：清理站点数据、更换浏览器／设备或部分隐私模式会使作品丢失；跨设备或长期保存请下载 JSON。数据库写入是异步的，关闭前应等待“已保存”；存在尚未保存内容时会请求浏览器显示离页提醒，但系统强制结束进程时无法保证最后一个未完成写入。

点击左上角项目名称即可重命名：`Enter` 确认，`Esc` 取消，移开焦点也会提交；名称最多 100 个字符，清空或只填空白后提交会恢复为 `Untitled`，过长时在顶栏省略显示。JSON 项目文件及 SVG／PNG 图片均按当前项目名称下载，自动处理非法文件名字符，避免重复扩展名。默认名称对应 `Untitled.json`、`Untitled.svg` 和 `Untitled.png`。打开项目后按文件名（去掉末尾 `.json`）命名，载入示例后使用模板名称，之后均可手动修改。

名称随各张画布独立恢复；没有有效名称时显示 `Untitled`。名称不参与几何撤销／重做，也不写入项目 JSON，因此不会改变既有项目格式；跨设备打开时仍以下载文件的名称为准。

旧的版本 1 项目仍可读取；包含独立线段／圆弧连接的项目使用版本 2，以保留已有点之间的引用关系。

项目格式支持版本 3，用于保存数学类型及原有局部绕行声明；一般路径连接绕行和两岸联动避让使用**版本 4**；原路径拆分后单独设置保留段外观或标签时使用**版本 5**；保存自动法向跟随或手动定向规则时使用**版本 6**。单源局部绕行继续使用 `targetSegmentId`；角点还保存 `exitSegmentId`。连接绕行保存真实源接入位置、半径及偏好间距；两岸避让保存父绕行、孤立奇点和公共半径。重新打开时严格校验全部依赖并重建几何，不保存生成端点，也不复制真实奇点。继续读取版本 1／2／3／4／5／6，并按作品实际内容选择最低必要版本。文件上限为 2 MB，父子绕行合计最多 1000 个，派生点和路径段各最多 10000 个；无效依赖、循环引用或超限文件会明确报错，本地损坏草稿保留以便恢复。

## 奇点与路径绕行

独立标记点和围道顶点均可设置“数学类型”：**普通点、孤立奇点、支点**，其中孤立奇点包含极点等，**设置类型本身不会自动改变路径**。旧项目中的极点统一显示为孤立奇点，重新选择同一分类不会改写原记录。已有顶点与独立点工具共用稳定 ID，独立公式不参与绑定。孤立奇点和支点使用同一套几何构造；可显式建立平行连接段来表示割线两岸，但不从表达式推断割线、不计算分支值。新载入的凹口／割线模板已包含对应绑定，旧项目中的手工路径不会自动转换。

选择奇点后，点击唯一的**添加绕行**入口，再在画布上选择源路径。系统按奇点是否在路径上自动确定构造，不需要选择接入方式；绕行不验证函数的分支或解析性。

#### 路径外的奇点与两岸避让

奇点不在所选路径上时，默认从最近的法向位置接入；与奇点同心的圆弧则保留点击位置的方向。系统从真实源路径接出两条平行直线，以绑定奇点为圆心绕行后接回，并替换原路径的相应区间；可从直线、真实圆弧、开放／闭合混合链接入，也可跨共享顶点或多个源段。独立连接只在所选单段内接入，不隐式合并不同路径分量。圆形围道的接缝可直接点选，用于建立钥匙孔围道；同一操作不限于圆形或正实轴方向。

用**绕行半径**、**两岸间距**和**开口朝向（度）**分别调整形状。间距为数学长度，须大于 0 且小于父绕行直径；修改一项不会自动改变另外两项。朝向以正实轴为 0°，逆时针为正，支持 45°、负角及超过一周的有限角度。系统将朝向转换为真实源路径上的接入位置；无有效交点、相切、交叉或子避让失效时说明原因，保留原作品。

新建路径外绕行默认**法向跟随**：移动奇点时，通道中线经过奇点并垂直于源路径切线，两岸保持平行。直线对应垂足接入，圆弧对应径向接入；奇点恰在圆心时保留已选方向。手动输入朝向或拖动接入口后切换为**手动定向**：以后移动奇点保持该数学角度，并重新计算接入口，不固定旧接入点。点击**恢复法向跟随**可返回默认方式。

拖动接入口时，开启吸附会在 8 CSS 像素内对齐水平、竖直或源路径法向；不默认吸附 45°，其他角度可以精确输入。Alt 临时绕过吸附，关闭“网格吸附”也会关闭开口吸附；数值朝向不做吸附。

奇点靠近绑定边界时，两岸逐渐缩短，接合位置改由源路径与绕行圆的真实交点决定；在直线边界上形成半圆，在圆弧边界上形成真实交点间的绕行圆弧，与直接在该处添加绕行一致。接近边界时开口可能大于偏好间距，偏好值及部件设置仍保存；移回内部后恢复平行两岸。边界上的连接绕行奇点可以拖离源路径，不会被永久锁在边界上。已有子避让若因此失效，整次修改仍会被拒绝，不静默删除子避让。

若通道中还有孤立奇点，选择该奇点后添加绕行，**点击任一可见岸线即可一次避让两岸**。两岸圆弧共用该奇点和公共半径，分别与有限岸线求交，并向通道外侧绕行；两岸样式和标签可单独设置。已有孤立奇点绕行若同样具有两条非零平行连接段，也支持此操作，不要求父点必须是支点。

子避让中的“两岸间距”修改的是**整个父通道**，会同步检查其他子避让；每个孤立奇点仍有自己的半径。半径较小时，圆盘已完全处于通道留空区，可保留为“当前无需额外绕行”，重新增大半径后恢复圆弧及外观。可沿通道设置多个孤立奇点，但避让区间不能相交或相切，也不能侵入通道端部；不自动合并多个圆盘或继续任意嵌套。

父岸的标签与箭头按其自身剩余片段总弧长的中点定位，子圆弧独立计算。父岸暂时消失时不显示其标签，但保留设置，岸线恢复后重新显示。

拖动任一父／子圆弧端点可调整该绑定的公共半径；子避让两岸同步变化，一次拖动一步撤销，Esc 恢复。取消子避让恢复相应岸线，保留父绕行；取消父绕行会一起清理其子避让，但保留真实奇点。父几何或真实奇点移动时整体重算，任何依赖失效都保留上一次有效作品。

也可以直接在画布上调整：

- **拖动圆弧端点**：改变公共绕行半径，圆心、两岸间距和开口朝向不变。
- **拖动原路径上的接入点**：同步调整两个接入位置，圆心、半径和两岸间距不变；沿真实源路径定位，不做网格吸附。
- **拖动独立双箭头手柄**：对称拉开或收拢两岸，半径和开口朝向不变；属性面板的间距数值同步更新。
- **改变朝向**：在属性面板输入角度，两接入点一起重新定位。

所有端点手柄都在真实几何位置，不移位、不合并、不加引线；独立双箭头位于通道旁，并避开端点及半径手柄，不代表一个数学端点。端点命中范围重叠时优先操作距离指针最近的实际点；完全重合时优先当前选择，否则优先真实顶点或奇点。这些操作都支持一步撤销和 Esc 恢复；不能满足平行接入或使子避让失效的位置不会改变作品。

#### 路径上的奇点与共享角点

绕行必须显式绑定到源路径，支持围道或独立连接的直线、真实三点圆弧，以及围道共享顶点的一入一出角点。同一源路径可绑定多个不同奇点，但各自的源参数占用区间不能相交或相切；角点同时占用进入段的尾部和离开段的首部。

- **单源直线**：奇点位于两端点之间时使用所选侧半圆。
- **单源圆弧**：将以奇点为圆心的避让圆与真实源圆弧求交，按源行进方向的两个交点裁剪局部路径，再接入绕行圆弧；剩余源段仍是真实圆弧，不以弦替代。要求有两个不同的有限弧交点、裁剪区间位于避让圆内；相切、重合、缺少交点或半径覆盖源端点会明确拒绝。
- **共享角点**：复用设为奇点的围道顶点，点击任一相邻可见源段会自动确定进入和离开两个目标。进入段取最后一个有效交点，离开段取第一个有效交点，支持直线／圆弧混合；填充沿切角后的闭合边界计算，不再回到原角点。默认选择较短圆弧，也可选择另一侧的长弧。只有一个可见邻段的开放端点不能创建角点绕行，面板会说明缺少的依赖，不会隐式补边。

绕行圆弧的**圆心始终强绑定到奇点坐标**，不是可自由拖动的三点圆弧。移动奇点时，圆弧及连接段一起重算，半径保持已应用值；拖动源端点也会重算连接关系，圆心仍留在奇点。移动奇点或源端点时整体校验，冲突修改会保留原图形；删除奇点或任一依赖源段会清理整个绑定。反转围道同步交换绕行侧向与进出部件的样式、标签，角点还会交换进入／离开源段引用，独立连接保持方向。已有绕行需先取消才能将奇点改回普通类型；源路径的几何修改也必须通过绑定有效性检查。

绕行创建流程中的目标选择与参数预览使用独立临时草稿，只有应用后才写入作品并计为一步撤销。有效预览直接显示应用后的完整围道，包括源路径裁剪、闭合填充、箭头和标签；不叠加旧线，取消立即恢复，应用时几何保持一致。预览不参与点选、框选、本地自动保存或项目与图片导出；按 `Esc`、主动切换绘图工具、收起创建属性面板或载入作品会取消创建。窄屏选择目标时临时收起属性面板，选定后恢复面板；无效目标会自动展开并聚焦错误说明，点击“重新选择目标”保留原奇点并返回画布继续拾取。选择期间仍可平移和缩放画布，重试或 `Esc` 后不会被过期错误重新夺走焦点。

参数预览期间也可移动真实奇点：接入口按当前法向跟随或手动定向规则同步更新，接近边界及移回内部的行为与应用后一致。移动真实奇点仍属于正常编辑，但绕行草稿本身在应用前不会保存；应用时沿用当前预览的接入口和形状。

应用绕行后，开启“显示编辑手柄”会显示绕行圆弧的两个新端点。选择工具下拖动任一端点即可调整公共半径，另一端点、绕行弧及两侧连接同步重算；圆心保持绑定奇点，两点不能独立拖开。无效半径或路径冲突保留上一次有效形状，整个拖动计一步撤销，按 `Esc` 恢复两端及完整围道。键盘聚焦端点后按 Enter 或空格可定位绕行属性，再用数值输入精确调整。手柄不参与普通点连接，不写入项目文件，也不会出现在图片导出中；预览期间仍通过半径表单调整候选形状。

路径上和路径外的初始半径使用同一规则，不区分模板：优先复用作品已有父绕行半径；没有时按完整源图形数学范围的对角线约 1/20 推荐，并取便于阅读的数值。两岸孤立奇点避让优先沿用所属父绕行的半径，不再按通道间距另取较小值，使同一围道的小圆弧尽量等半径；钥匙孔避让奇点模板的三个小圆弧半径均为 0.5。标准圆形模板的推荐半径为 0.4。不因某条边较短就自动缩小，只有局部构造确实容纳不下时才逐次减半；路径外初始间距为半径的 0.6 倍。这是新建时的推荐规则，不会强制同步已有或手动修改的半径。缩放、标签和派生绕行不改变这个基准，也不重算已应用尺寸。建议值仍须通过完整交叉检查，可在预览中修正。直接绕行面板显示半径范围及交点裁剪说明，角点明确列出进入和离开两个目标。第一次获得有效角点几何时初始化默认短侧；若已显式选择侧别，修正参数仍保留该选择。参数预览通过检查后点击“应用绕行”。同一奇点和源目标重复创建会定位已有绑定，角点点击任一邻段都复用同一绑定。奇点和所有依赖源段的属性面板均列出相关绕行，对象列表按实际行进顺序列出拆分后的路径对象，而不把整条展开路径合成一行。

例如矩形一条边接入内部奇点后，对象列表依次显示**保留段 1、进入连接段、绕行圆弧、离开连接段、保留段 2**。各段可分别选择并设置颜色、线宽、线型、标签及方向箭头；修改一段不修改另外几段。箭头开关继承为开启时，新构建的各段立即显示自己的箭头，无须重新勾选；沿用普通路径的过短线段不显示箭头规则。移动奇点或调整半径只改变形状，不改变各段自己的外观设置。

点击绕行部件可持续编辑同一绑定：数值输入以 **Enter 或移开焦点**提交，完整有效数值立即接受几何检查，一次提交计一步撤销；空串、单独的正负号和非法数值保留为草稿，不写入作品。半径和间距须为正数，朝向允许零和负数。已有绑定的数值若被几何检查拒绝，输入恢复为已应用值并显示错误，拒绝操作不计入撤销。路径上的直接绕行提供左／右分支选项及交点裁剪说明，开口由真实交点决定，不虚构独立间距或朝向。

旧项目仍可读取，载入不改变原形状。没有跟随规则的旧连接绕行，在实际单独移动其奇点时启用法向跟随；整体平移依赖组不迁移，亦可主动点击“恢复法向跟随”。具有两条非零连接段且可保持原形状的旧直线离线绕行，在编辑几何时自动转为独立参数构造，保留原间距、样式、标签和子避让；只查看或修改外观不会改写声明。旧圆弧直接裁剪、开口达到直径、连接段缩为零等不能无损转换的情形继续保留原约束。仅这些兼容情形仍可能显示“偏好开口宽度”和“实际开口宽度”，修改半径时偏好宽度按旧比例变化。

半径必须是有限正数，且严格小于面板显示的必要上限：既不能触及源段外部端点，也不能侵入其他绕行的源参数占用区间；角点的原奇点顶点是裁剪中心，不是这个外部端点限制。圆弧／角点仍需满足实际有限交点条件，所有模式均须通过其他路径交叉检查和数值安全检查。直线离线“偏好开口宽度”必须大于 0 且不超过直径，过小开口会按连接安全约束展开为实际宽度；不要把显示范围当作任意图形都可接受的保证。

当路径坐标尺度差异过大，无法可靠判断绕行是否相交或安全投影时，预览会说明涉及的绑定、路径和数值原因，保留可编辑草稿供修正；无效应用和已有作品的无效编辑均保留原作品与历史。请调整坐标尺度或绕行参数后重试，不能仅通过放大或减小半径绕过检查。

“定位奇点”“定位原路径”及角点的“定位离开路径”只切换选择；奇点按实际来源定位顶点或独立标记。“取消绕行”取消当前绑定并恢复其占用的原直线／圆弧部分，同一路径的其他绑定不受影响。保留段的外观和标签分别保存；进入连接段、绕行圆弧、离开连接段默认继承源路径线条，也可分别覆盖。原源标签首次拆分时仅由第一个可见保留段继承一次，不复制多份；之后各段自行设置标签。暂时缩为零或隐藏的部件保留设置，重新出现后恢复显示；取消绑定时恢复原源基础设置，撤销可恢复拆分对象及其设置。派生部件不提供自由端点坐标或三点圆弧经过点编辑。

取消“闭合围道”后，暂存闭合边上的绕行、保留源路径及标签仍保留逻辑选择和设置，属性面板会解释其暂不显示的原因，并可继续编辑绑定；多选面板也提供“编辑暂存绕行”入口。角点任一所需源段暂时隐藏时，保留整个绑定，但不会裁剪仍可见的另一段。重新闭合后恢复显示，并重新检查交叉冲突。

改变开口朝向只能接入当前可见的源区间，不能把可见绕行移到暂存关闭边而使其消失；若当前源依赖已暂存，需先恢复闭合再调整朝向。

载入含绕行声明的项目后，画布显示实际绕行路径，围道填充沿绕行边界计算，独立连接不参与填充。标签和箭头位于各自路径对象的数学弧长中点；子避让造成一条逻辑岸线多次裁剪时，该岸线自身的箭头仍只显示一次，子圆弧按自己的设置绘制。自动生成的连接点不显示为自由端点，圆心绑定的绕行圆弧不提供三点圆弧的经过点手柄。“适应图形”会包含实际圆弧的极值和标签，非等比轴下仍保持数学圆心与半径。

框选按各路径对象的完整实际范围判断，点击保留段只选择和编辑该保留段。同一岸线被子避让拆成多段后，须框住其全部可见保留片段才选中该岸线；子避让圆弧仍单独选择，岸线的框选结果保留可拖动选框。拖动选框时，所选绕行部件会带动对应源端点与奇点，角点的两条源依赖和重复选中的点只移动一次；整体围道平移也包含其绑定奇点。批量颜色、线宽和标签字号修改只写入明确选中的对象。删除绕行部件几何会取消该绕行，删除部件标签只隐藏标签；删除源路径或其保留部分仍会删除源路径并清理相关绕行，不自动补边。自动接合点不能作为自由点吸附或连接目标。

## 图片导出

图片支持 **SVG** 和 **PNG**，可选择白色／透明背景，以及是否包含坐标轴、坐标轴刻度标签、网格和围道端点标记。导出默认不包含坐标轴刻度标签，可按需勾选；该选项独立于画布显示设置，仅在包含坐标轴时生效。画布的刻度标签开关位于“视图设置 → 显示与吸附 → 显示坐标轴刻度标签”。SVG 保留矢量路径和数学字形；PNG 提供 **1×、2×、3×** 分辨率倍率，默认使用 2×，菜单会显示对应的实际尺寸。

默认使用“适应图形（完整导出）”：按完整图形、标签及留白自动确定长宽，宽图会导出为宽图；过大的图形会在导出副本中等比适配。也可选择“当前视图（800×600）”，按当前中心和缩放导出固定区域。SVG 和 PNG 使用同一导出范围，导出不会改变编辑画布或历史。

含绕行的完整导出会包含实际连接段、圆弧、切角后的填充、方向箭头，以及源路径和局部标签的像素偏移。“端点标记”控制普通围道端点；声明数学类型的顶点是作品中的语义点，即使关闭编辑辅助点或导出端点标记也保留，并且只输出一个真实点圆，不复制独立标记。自动生成的接合点、经过点手柄、命中区、选择高亮和预览均不导出；尺寸适配保留源坐标、绕行半径和绑定关系。

## GitHub Pages 发布

在线站点由本仓库独立发布到 <https://huanyushi.github.io/contour-editor/>。Vite 的 `base` 配置为 `/contour-editor/`，确保脚本和样式使用正确的项目路径。

向 `main` 分支推送后，[部署工作流](.github/workflows/deploy-pages.yml)会自动安装 npm 依赖，依次进行代码规范、格式、单元／组件测试和生产构建，不再安装 Chromium 或运行完整浏览器测试。以上检查通过后，才将 `dist/` 作为 Pages 产物交给部署任务；任一步失败都会阻止部署。单元／组件测试使用两个 worker。也可以在仓库的 Actions 页面手动运行“Deploy to GitHub Pages”。构建产物通过工作流上传，无需提交 `dist/`，也无需同步博客仓库。

完整浏览器测试由[独立工作流](.github/workflows/browser-tests.yml)运行：针对 `main` 提交或更新 PR（合并请求）时自动触发，也可在 **Actions → Browser tests → Run workflow** 中手动运行。不设置定时任务；直接推送到 `main` 不触发浏览器测试。该工作流安装 Chromium 及其 Linux 系统依赖，并使用两个 worker 运行完整的桌面及窄屏测试，不参与 Pages 部署的依赖关系。浏览器测试失败不会阻止或自动回滚直接推送触发的部署，因此较大改动和正式发布前仍应运行完整检查。

首次启用时，仓库的 **Settings → Pages → Build and deployment → Source** 应选择 **GitHub Actions**。部署结果可在 Actions 中查看：`build` 和 `deploy` 均成功后，通过部署记录中的站点链接访问并刷新确认。

## 开发与验证

界面布局位于 `src/app/`，围道模型和编辑位于 `src/features/contour/`：`selection/` 管理选区，`interaction/` 协调手势与快捷键，`avoidance/` 处理绕行，`scene/` 负责派生场景和绘制。`model.ts`、`history.ts`、`ContourCanvas.tsx` 等入口保留在 contour 根目录。持久化及导出位于 `src/features/project/`，其中 `format.ts` 负责格式与序列化，`validation.ts` 统一接受校验。数学基础代码仍放在 `src/lib/`。完整代码导航及现行说明与历史记录的区别见[文档入口](docs/README.md)，实现约定见 [AGENTS.md](AGENTS.md)。

| 命令                                      | 用途                |
| ----------------------------------------- | ------------------- |
| `npm run lint`                            | 代码规范检查        |
| `npm run format` / `npm run format:check` | 格式化／格式检查    |
| `npm run typecheck`                       | TypeScript 类型检查 |
| `npm test` / `npm run test:watch`         | 单元和组件测试      |
| `npm run test:e2e`                        | 浏览器测试          |
| `npm run build`                           | 生产构建            |

浏览器测试使用 Playwright，首次运行前需要安装 Chromium：

```bash
npx playwright install chromium
```

Linux 系统依赖可通过 `npx playwright install-deps chromium` 安装，或用 `npx playwright install --with-deps chromium` 一并安装浏览器和系统依赖；安装系统库通常需要管理员权限。若提示缺少 `libasound.so.2` 等共享库，应先补齐运行环境，浏览器启动失败不代表产品断言失败。中文截图需要中文字库，例如 `fonts-noto-cjk`。

本地完整验证可依次运行 `npm run lint`、`npm run format:check`、`npm test -- --maxWorkers=2`、`npm run build` 和 `npm run test:e2e -- --workers=2`。build 已包含 TypeScript 检查。浏览器测试会自动启动**开发服务器**，以桌面覆盖完整流程，并在窄屏下验证与尺寸、焦点或覆盖层有关的交互；失败时保留轨迹供排查。生产构建通过与开发服务器上的交互测试是不同检查，不能据此声称已验证生产构建的全部运行行为。
