## 代码导航

| 位置（相对 `src/features/contour/`） | 主要职责                                             |
| ------------------------------------ | ---------------------------------------------------- |
| 根目录                               | 模型、撤销历史、画布、通用表单和模板                 |
| `selection/`                         | 选区查询、编辑、范围计算、平移与多选属性             |
| `interaction/`                       | 手势协调、拖动、路径吸附、快捷键和滑条操作           |
| `avoidance/`                         | 绕行的构造、编辑、参数和属性面板                     |
| `scene/`                             | 派生场景、对象查询、路径拼接、投影、SVG 绘制及缩略图 |

`src/features/project/` 负责项目文件的读写、校验和导出；`src/lib/` 存放几何等纯函数。单元测试通常与被测模块放在一起。
