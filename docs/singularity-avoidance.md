# 奇点绑定与半自动绕行：实现约束

本文记录当前实现的模型、几何和维护边界。使用步骤见 [README](../README.md#奇点与路径绕行)，通用开发约定见 [AGENTS.md](../AGENTS.md)。

## 功能边界

- 界面提供普通点、孤立奇点（含极点等）、支点三类，对应 `ordinary | isolated | branch`。属性面板和对象列表共用同一分类／名称映射，不为旧的极点分类保留单独选项或算法。
- 文件读写继续保留旧值 `pole`，展示时映射到孤立奇点；仅查看或重新选择同一显示分类不改写旧记录，不新增历史。非普通类型共用同一套几何绕行；类型本身不会创建绑定，公式不参与绑定。
- 用户显式选择奇点、源路径、半径及适用侧向。支持围道与独立连接中的直线、真实圆弧，以及围道共享顶点的一入一出角点。
- 不从函数表达式识别奇点，不自动规划整条围道，也不证明积分区域、解析性或绕数正确。
- 数学类型不自动产生支割线。支持显式通用平行连接及两岸孤立奇点联动，但不建立正式支割线对象、不做函数穿越检测或分支选择。新载入的半圆凹口、钥匙孔、钥匙孔避让奇点及 Bromwich 割线模板使用真实绕行声明，其余五种保留基础路径；旧项目中的手工路径不自动迁移。

## 源模型与派生场景

源文档只保存真实顶点、独立点、源路径和 `avoidances` 声明，不保存生成端点、圆弧经过点或几何缓存。

| 字段                       | 含义                                        |
| -------------------------- | ------------------------------------------- |
| `id`                       | 全文档唯一且稳定的绑定 ID                   |
| `markerId`                 | 奇点 ID，可引用独立点或围道顶点             |
| `targetSegmentId`          | 单源路径，或角点的进入源段                  |
| `exitSegmentId`            | 仅角点使用，指向共享顶点的离开源段          |
| `radius`                   | 正的数学半径                                |
| `side`                     | 沿源行进方向的 `left \| right` 分支偏好     |
| `openingRatio`             | 直线离线模式的偏好开口／直径，范围 `(0, 1]` |
| `partStyles`、`partLabels` | `entry \| arc \| exit` 部件的外观与标签覆盖 |

上表是缺省 `kind`／`kind: local` 的旧声明，继续保留版本 3 语义。版本 4 增加两种源声明：

- `corridor`：`id`、`markerId`、源锚点 `anchor`、`radius`、数学总间距 `gap`，以及 `entry | arc | exit` 外观和标签。锚点为源段有向参数或真实共享顶点＋宿主段上下文；不保存派生交点。
- `bank-clearance`：`id`、`markerId`、`parentAvoidanceId`、公共 `radius`，以及 `bank-entry | bank-exit` 的独立外观和标签。父可以是新连接绕行，也可以是具有两条非零连接段的旧绕行；不能引用子绑定或生成片段索引。

父构造统一输出裁剪／占用区间、部件和可选 `bankPair`。子绑定依赖几何能力而非父点数学类型。先计算全部父几何，再对同一未裁剪父岸计算所有子避让，最后按每岸参数排序拼接；结果不得取决于声明数组顺序。实际交叉验证只针对最终场景，不重复绘制或校验已被替换的父岸。

同一点和相同源依赖的重复创建复用已有绑定。角点引用一条进入源段和一条离开源段，不能用同坐标的另一个点代替共享 ID。

`sceneObjects.ts` 的源查询只返回源对象；派生查询通过 `resolvedScene.ts` 获取实际点、路径、逻辑链、标签和来源映射。绘制、命中、框选、视图范围、填充及导出使用同一派生语义，不能重新绘制被替换的源区间。

## 几何规则

所有构造使用数学坐标，CSS 像素只用于显示、标签偏移和指针吸附。归一化和求交不得修改第三方全局容差；数值退化时明确拒绝，而不是生成不可可靠重建的图形。

### 单源直线

源为 `A → B`，单位切向量为 `t`，左法向量为 `n`，长度为 `L`。奇点为 `C`，沿线位置 `s = dot(C - A, t)`，离线距离 `h = dot(C - A, n)`，投影为 `Q = A + s t`。

- 要求 `[s - r, s + r]` 严格位于 `(0, L)` 内，即使实际开口更窄也保留完整半径占用。
- 在线时以 `C ± r t` 为端点，左右半圆分别经过 `C ± r n`。
- 离线时开口朝向原路径，连接段沿法向，外侧圆弧不小于半圆。偏好宽度 `wPreferred = 2 r × openingRatio`。
- 当 `abs(h) < r`，`wMinimum = 2 sqrt((r - abs(h)) × (r + abs(h)))`；否则为零。
- 实际宽度 `w = max(wPreferred, wMinimum)`，半宽 `a = w / 2`，`k = sqrt((r - a) × (r + a))`。
- 原线连接口为 `Q ± a t`，圆弧端点为 `C ± a t - sign(h) k n`，经过点为 `C + sign(h) r n`。
- 零长度连接段省略并复用接合点，但仍保留逻辑来源。自动展开开口不覆盖偏好比例。

### 源圆弧与共享角点

- 源圆弧与以奇点为圆心的小圆求两个不同的有限弧交点，按源参数裁剪圆内局部区间；剩余源段仍是真实圆弧，不用弦替代。
- 角点从进入段取最后一个有效交点，从离开段取第一个有效交点，支持直线／圆弧混合。两段分别占用尾区间和首区间，默认短圆弧，可切换另一侧。
- 第一次有效构造才初始化默认侧；修正无效建议半径不能覆盖用户已经显式选择的侧。
- 相切、重合、缺少交点、覆盖源端点或无法可靠表示圆心／半径时拒绝。
- 同源占用区间不能相交或相切。新增部件不能与其他实际路径产生非接合交点或重叠；已有普通源路径之间的交叉不追溯禁止。

### 通用平行连接

- 不按模板或闭合状态分流。逻辑源链依稳定端点 ID 排序，独立连接以单段为界；替换区间可跨多个源段和环路参数零点，中间源段仅在派生场景省略。
- 目标 `C`、真实源接入点 `P` 确定朝外单位向量 `d=(P-C)/|P-C|`，法向 `n=(-d.im,d.re)`。以 `b=gap/2`，要求 `0<b<r`；内端点为 `C+sqrt(r²-b²)d±bn`，从内端点沿 `+d` 与有限真实源路径求交。
- 取能包含锚点的唯一局部有向区间，原区间须位于两岸通道内且不能侵入避让圆；内弧经过 `C-rd`。进出与弧方向服从源行进方向，不固定屏幕上下。
- 数值求解使用目标点局部尺度，拒绝重合、相切、歧义、无法区分的开口或无法表示的圆。不得通过超长线段近似无限射线，不用弦替代源圆弧。
- `gap` 和半径分别编辑，不自动互改。旧直线 `openingRatio`、自动展开和完整半径占用仍由兼容适配保留；自动展开后连接段为零时不暴露 `bankPair`。
- 新建仅保留“添加绕行”：路径上的奇点使用直接交点／角点构造，路径外使用 `corridor`。直线与非同心圆弧默认最近法向接入，同心圆保留实际点击方向。初值使用下节的统一数学尺寸及局部适配规则，不依赖视图缩放。
- `开口朝向（度）` 支持任意有限角度，正实轴为零、逆时针为正。`anchorForConnectedDirection` 将中心射线与有限源链求交并返回真实 `anchor`；编辑器另外在 `alignment` 中保存手动角度，以便移动奇点后重新求交。改变方向固定 radius／gap，最终接受仍须通过完整父子场景验证。
- `editableAvoidance` 只为可无损转换的旧直线离线声明提供统一编辑视图；转换前验证新构造有效且进出端点、接入点和弧经过点与旧形状一致。实际几何编辑才转换，保留实际间距、ID、覆盖外观、标签和子依赖。路径上的直接构造、旧圆弧、直径开口和退化连接继续兼容，不能为删除旧 UI 而删除其几何规则。
- 方向求解只使用当前可见源链，并以完整存储源链重建候选，确认实际裁剪不依赖隐藏关闭边；不能借角度编辑将可见绕行迁移为暂存绑定。主动隐藏原有依赖时暂存绑定的规则不变。

### 跟随、边界过渡与统一初值（版本 6）

- `CorridorAvoidance.alignment` 可选：`normal` 自动法向跟随，或 `direction` 保存数学角度。省略时载入保留旧形状；实际单独移动旧 corridor 的奇点才启用 normal，整体平移旧依赖组不迁移。手动拖接入口或输入角度设为 direction；恢复法向跟随重新投影。
- 自动法向使用真实源几何，不使用屏幕距离决定方向；直线垂足、圆弧径向，同心时保持原 anchor。同一圆支撑上的连续圆弧可跨接缝，不能把可见绕行迁入隐藏边。奇点与源接入点重合时，可选 normal.angle 仅记录侧别，防止反转后翻面，不作为手动角度。
- `buildApproachingAvoidance` 在远离源时复用严格平行构造；触及绕行圆时，计算源路径与平行岸线／单位绕行圆的有限交点。近边界允许一岸或两岸消失，绕行弧保持同一圆心、半径与 ID。手动斜接入先在开口旁触圆时，裁剪共同覆盖圆盘接触与接入口之间的短源区间，避免留下与圆相切的碎片；完整交叉检查仍决定接受。
- 偏好 gap 不随移动而改写，临时消失的 entry／exit 外观继续保留。真实端点仍是半径控件；无完整 bankPair 时不生成接入／间距手柄，也不把失效子避让静默删除。
- 开口拖动的吸附候选为水平、竖直及可用源法向，按接入口屏幕误差不超过 8 CSS 像素选择；只使用完整几何验证通过的候选，均不可用时退回未吸附位置。Alt 或关闭吸附绕过，数值角度不吸附。
- `defaultAvoidanceRadius` 只测真实源几何范围，不测标签、派生图形或 viewport。优先复用已有父半径，否则取数学范围对角线的 1/20 并保留一位有效数字；所有模板共用，初始 gap=0.6r。两岸孤立奇点避让优先取所属父声明的半径（包括旧局部绕行父声明），不按通道间距或岸线长度另设默认尺寸；这只统一新建初值，不联动改写已应用或手动设置的半径。局部构造不适配时逐次减半（最多 16 次），仍无效则保留可修正草稿；作品交叉冲突不通过暗自无限缩小规避。
- 含 alignment 的文件写版本 6；版本 1–5 不能混入跟随规则，版本 6 继续支持 pieces。预览、已应用画布及导出均使用同一构造，不存派生点或不同的导出几何。

### 两岸孤立奇点联动

- 真实孤立奇点 `D` 位于两岸之间，使用公共半径 `ρ` 与两条有限岸线求交，裁剪圆内区间，分别选通道外侧的圆弧。它是局部“原通道排除区与圆盘的并集”边界，不是对两岸分别套旧的包围大弧算法。
- 中线情形每岸交点的沿线半宽为 `sqrt(ρ²-b²)`；两岸有间距时，各外侧弧可以小于半圆。允许偏离中线及仅一岸受影响。
- 圆盘完全位于通道内或仅与岸相切时不生成退化弧，保留声明、参数和两岸覆盖。此规则不改变旧局部绕行的相切拒绝约定。
- 子占用按父 ID 和逻辑岸名校验，相交／相切拒绝；真实奇点移出条带、交点侵入父岸端部或与其他实际路径冲突时原子拒绝。不自动合并圆盘或创建任意深度依赖。
- 父参数修改重算全部子；子属性间距明确修改父通道。创建时对父间距的修改留在候选文档，应用父 patch 与子声明为一步历史，取消全部丢弃。
- 取消子只恢复其岸线；取消父或实际删除任何占用源依赖时级联清理子，但不删除真实奇点。仅源依赖隐藏则父子一起暂存；失效引用不得被当作删除而静默清理。
- 父／子圆弧端点只调各自公共半径。命中重叠时比较指针与全部实际端点、真实点的完整屏幕距离；完全重合时优先当前选择，否则优先真实点，不依赖 SVG 绘制先后。逻辑岸分段后的箭头和标签只各显示一次。
- 选择生成的岸线片段时存储稳定逻辑部件 ID，而非临时裁剪片段 ID；重新拼接、切换为无需裁剪状态后保留属性编辑器与输入焦点，多选按逻辑部件去重。
- 源接入点拖动同步定位两端，固定半径和 gap。指针投影到同一可见有限源链，按所在岸的有符号半间距反求中心射线，再求真实 anchor；不执行网格吸附。完整源链复验裁剪不能依赖隐藏边，最终父子场景原子接受。
- `AvoidanceHandles` 的端点控件位于实际端点，不移位、不合并、不加引线；独立双箭头图标沿通道法向调整总间距，保持 radius／anchor，基于手势开始快照计算。先收集全部真实点和端点，再为图标寻找不重叠的屏幕位置，不把图标存为数学端点。

## 编辑、预览与历史

- 圆心始终绑定奇点。移动奇点、源端点或整体选区时，原子重算全部依赖；失败保留上一次有效文档。
- 生成的圆弧端点控制公共半径，源接入端点同步调整接入位置，双箭头控制总间距，均不是独立自由点。拖动时重算形状，不改各路径对象自己的外观记录，不能自由拖动三点圆弧的经过点。
- 手柄仅在开启编辑手柄且不处于创建流程时显示；不参与普通点连接、项目持久化或图片导出。键盘激活可定位参数表单。
- 拖动使用 `canvas` owner 事务，一次拖动一步历史，Esc 恢复完整快照。选择、视图和创建草稿不进入文档历史。
- 有效预览显示完整候选场景，应用后几何不跳变；无效候选显示错误并保留已应用图形。预览不进入草稿、项目保存或导出。
- 完整预览期间保留不可见的已应用路径层。`serializeSvg` 仅在克隆树中移除预览并恢复原层，确保直接序列化编辑画布也不导出候选绑定。
- 每个可编辑路径对象按有效样式决定自己的箭头，位置为自身数学弧长中点，不区分“继承开启”和“显式开启”；原有 20px 过短对象限制不变。父岸内部裁剪按该岸自身剩余片段放一次箭头，子圆弧按自身设置绘制。
- 原路径保留段通过 `SourcePieceBoundary` 的两端绕行 ID 标识，不用浮点参数或数组下标。`gap:...` 保留实际绘图 ID，`piece:...` 为稳定可编辑别名；点选、列表、标签、样式及选择范围统一归一到对象身份，不能再把保留段外观动作映射到整个源对象。
- `PathSegment.pieces` 仅保存各保留段的外观／标签覆盖；几何仍由源及绕行构造派生。原源标签只由首个可见保留段继承一次。暂存、参数变化或暂时省略保留设置；删除依赖清理相关覆盖，反转交换边界，撤销恢复完整快照。

源边暂时隐藏时保留绑定和来源映射；角点任一依赖隐藏时，两侧都不裁剪。重新显示须再次通过整场景验证。删除任一依赖清理整个绑定；反转围道交换进入／离开依赖、左右及对应部件外观，不反转独立连接。

## 指针吸附

独立点创建及已捕获源路径的拖动先投影到真实有限路径。网格吸附复用当前视图两轴的 `gridStep(scale, center)`，只选择指针 8 CSS 像素内、确实位于路径上的网格交点，否则保留路径投影。全屏幕矩阵用于距离；路径局部坐标用于成员检查，不能用某一轴的大坐标放大另一轴误差。

Alt 临时解除路径及网格吸附；精确数值输入不投影。几乎奇异的 CSS 变换若超过 10000 个格线切片，只检查就近候选后保留投影，避免指针事件中无界扫描。吸附不新增持久化附着关系。

## 文件、容量和验证

仅旧数学类型／局部绑定使用版本 3；含 `corridor`／`bank-clearance` 写版本 4；包含 `pieces` 外观记录写版本 5；保存 `alignment` 跟随规则写版本 6；含独立连接的普通文档可使用版本 2。继续读取版本 1／2／3／4／5／6，旧版本不得混入新声明。旧模板标签不用于推断类型。失效父引用、错误层级、版本不匹配或悬空源引用使整个文件读取失败，不静默删除数据。每条源路径的保留段覆盖最多 2001 条，边界不能重复，引用须为存在的父绕行；属性验证与文件读取共用同一规则。

文件最大 2 MB，绑定最多 1000 个，派生点和路径分别最多 10000 个。编辑接受和文件读取共用有效性、容量和投影检查，保证写出的文件能够重新读取；草稿只记录已应用模型。

| `avoidanceConstructionTable.ts`、`scenePathSplicing.ts`                    | 父子构造、源裁剪与部件拼接         |
| `src/lib/connectedAvoidanceGeometry.ts`、`src/lib/approachingAvoidance.ts` | 平行接入与近边界过渡               |
| `avoidanceFollowing.ts`、`avoidanceDefaults.ts`                            | 接入口跟随及统一默认尺寸           |
| `resolvedScene.ts`、`avoidanceValidation.ts`                               | 来源解析、实际场景与冲突验证       |
| `avoidanceModel.ts`、选择与历史模块                                        | 源更新、依赖维护和原子编辑         |
| `ScenePaths.tsx`、`CanvasScene.tsx`                                        | 共用投影结果绘制已应用场景和预览   |
| `src/features/project/`                                                    | 严格读取、容量约束、持久化和导出   |

以上省略路径的模块均位于 `src/features/contour/`。几何与状态规则用单元测试，表单用组件测试，真实拖动、布局和图片下载用相关 Playwright 场景；实际缺陷回归应保留，不用重复的模拟入口替代现有真实控件。
