# 奇点绕行：模型与实现

本文介绍奇点绕行的构造方法、保存方式和相关代码。基本使用见 [README](../README.md#快速开始)，通用开发约定见 [AGENTS.md](../AGENTS.md)。

## 绕行方式

编辑器中的点分为普通点、孤立奇点和支点。选择一个奇点及一段路径后，可以按它们的位置关系添加绕行：

- **奇点在路径上**：以奇点为圆心构造圆弧，用圆弧替换附近的一段路径。路径可以是直线、圆弧，或两段路径连接形成的角点。
- **奇点在路径外**：从路径引出两条平行的连接线，接到以奇点为圆心的圆弧上。两条连接线之间的距离称为间距。
- **两岸之间还有孤立奇点**：两条平行连接线称为两岸。可以在受影响的岸线上构造圆弧，避开两岸之间的孤立奇点。

半圆凹口、钥匙孔、钥匙孔避让奇点和 Bromwich 割线模板都包含可编辑的绕行。

## 数据如何保存

项目保存点、原始路径（称为源路径）和绕行参数。绘制时，程序根据这些数据计算圆弧与连接线，再将它们与保留下来的路径拼接。这组计算出的图形称为派生场景，编辑、预览和导出都使用它。

每条绕行记录都有自己的 ID、奇点 ID 和半径，具体字段随绕行方式而定：

| 绕行方式   | 主要字段                                   | 作用                                           |
| ---------- | ------------------------------------------ | ---------------------------------------------- |
| 路径上绕行 | `targetSegmentId`、`exitSegmentId`、`side` | 指定路径及绕行方向；角点使用进入和离开两段路径 |
| 平行连接   | `anchor`、`gap`、`alignment`               | 指定接入位置、两岸间距及跟随方向               |
| 两岸避让   | `parentAvoidanceId`                        | 指向提供两岸的绕行                             |

各部件的外观、标签和箭头位置分别记录在 `partStyles`、`partLabels` 和 `partArrowPositions` 中。

## 几何构造

以下计算都使用数学坐标。设奇点为 `C`，绕行半径为 `r`。

### 路径上的绕行

对于直线，设路径前进方向的单位向量为 `t`，左侧单位法向量为 `n`。绕行圆弧的两个端点是 `C - r t` 和 `C + r t`，圆弧经过 `C + r n` 或 `C - r n`，分别对应路径的左侧和右侧。

对于圆弧，以 `C` 为圆心、`r` 为半径的圆与路径求交，用绕行圆弧替换两个交点之间的部分。角点由进入路径和离开路径各取一个交点，连接成绕行圆弧。

### 平行连接

设路径上的接入位置为 `P`，从 `C` 指向 `P` 的单位向量为 `d`，将 `d` 逆时针旋转 90° 得到 `n`。当两岸间距为 `2b` 时，要求 `0 < b < r`。绕行圆与源路径之间有足够空间时，圆弧的两个端点为：

```text
C + sqrt(r² - b²) d + b n
C + sqrt(r² - b²) d - b n
```

圆弧经过 `C - r d`，两条连接线从圆弧端点沿 `d` 方向延伸至源路径。当绕行圆接近源路径时，程序根据实际交点调整圆弧和连接段，保持图形连续。

### 两岸避让

以两岸之间的孤立奇点为圆心，用户可以设置避让圆的半径。程序分别计算圆与两岸的交点，用位于通道外侧的圆弧替换受影响的岸段。根据奇点位置和半径，可能有一侧或两侧岸线发生变化。

## 编辑与预览

- 拖动奇点或相关路径时，绕行随之重新计算。圆弧端点用于调整半径，平行连接的接入点和双箭头手柄分别用于调整接入位置和间距。
- 平行连接可沿路径法向跟随，也可指定开口朝向。拖动开口时可以吸附水平、竖直或路径法向，按住 Alt 可临时解除吸附。
- 新绕行的初始半径优先参考已有绕行，否则根据图形的数学尺寸估算；平行连接的初始间距为半径的 0.6 倍。两岸避让优先使用所属绕行的半径。
- 创建绕行时，画布会预览调整后的图形，应用后将绕行参数写入项目数据。参数无法构造有效图形时，界面显示提示并保留原图形。
- 一次拖动记为一步撤销；拖动时按 Esc 可恢复操作前的状态。绕行各部件可以分别设置外观、标签和箭头。
